# Proyek Pemrograman Mobile

## Deskripsi
Aplikasi latihan untuk pembelajaran Pemrograman Berbasis Mobile menggunakan Flutter.

## Pengembang
Nama panggilan: Sapna / Akun GitHub: SapnaMaharani

## Status
Proyek awal perkuliahan.

## Tujuan
Proyek ini bertujuan untuk melatih penggunaan Flutter dalam pengembangan aplikasi mobile serta memahami alur kerja version control menggunakan Git dan GitHub.

## Rencana Fitur
1. Pendaftaran antrean layanan kesehatan secara online.
2. Akses kartu peserta digital atau KIS Digital.
3. Perubahan data peserta dan informasi fasilitas kesehatan.

## Cara Menjalankan
1. Pastikan Flutter sudah terpasang pada komputer.
2. Buka folder proyek melalui VS Code.
3. Buka terminal pada folder utama proyek.
4. Jalankan perintah berikut:

```bash
flutter pub get
flutter run
```
